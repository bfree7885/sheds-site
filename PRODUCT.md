# Sheds Platform

Sheds is a GIS-driven shed hunting platform designed to combine mapping,
ecology education, and field data collection.

## Core Goals

1. Help people understand where deer drop antlers and why
2. Build terrain-based shed probability heatmaps
3. Provide professional navigation tools for field exploration
4. Collect structured ecological data from user observations
5. Build a research-grade dataset for wildlife analysis
6. Publish research summaries through Field Notes

## Main Sections

### Home
Introduces the project and displays preview heatmaps.

### Field Guide
Educational resource explaining deer behavior, terrain patterns,
seasonal movement, and shed ecology.

### Field Notes
Research summaries generated by AI from wildlife research,
government reports, and university studies.

### Field View
Interactive map system with:

- GPS tracking
- offline maps
- terrain layers
- heatmap overlays
- user observation logging

## Data Collection

User observations should record:

- location
- terrain
- habitat type
- weather conditions
- antler characteristics
- estimated deer age class

This data will train AI terrain models that improve shed heatmaps.

## Long Term Vision

Sheds will eventually:

- produce ecological insights about shed distribution
- publish research articles
- generate datasets for universities
- support writing a book based on the collected data.
